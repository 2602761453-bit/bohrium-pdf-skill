# 版面判定方法与调参

## 为什么不用"找中间空白"的朴素做法

多数双栏 PDF 的正文栏缝并不是干净的空白带：通栏标题、通栏摘要、跨栏图注都会压过栏缝。若按"x 投影必须完全为空"找缝，这些块会把整页糊成一栏，结果就是左右栏逐行交替（串栏）。

这里改用**覆盖计数**：把 x 轴切成 1pt 的窄条，统计每个窄条被多少个正文块压住。栏缝处的计数显著低于峰值（只有跨栏块压过），于是"计数低且连续够宽"的带就能被识别为栏缝，同时天然容忍少量跨栏块。

## 判定步骤

1. **抽块**：`page.get_text("dict")` 取文字块，块内按行拼接，保留原始字符与换行；图片块跳过。
2. **页眉页脚**：块整体落在页高 7.5% 以上或 92.5% 以下，判为 `header`/`footer`，移出正文，但仍写入 `units[]` 与 `excluded[]`。
3. **找栏缝**：
   - 只接受中心落在页宽 18%–82% 之间的候选，避免把外页边距当栏缝。
   - 候选带内每个窄条的覆盖计数必须 ≤ 峰值 × 0.40。
   - 候选带宽度 ≥ 页宽 2%。
   - 带左右两侧各至少 3 个块，否则认为不是真栏缝。
4. **递归找第二道缝**：在已切出的左右半区内重复步骤 3，最多得到 2 道缝（即 3 栏）。
5. **分栏**：块横跨任一道缝 → 跨栏块（`column = -1`）；否则栏号 = 其中心右侧缝的数量。
6. **排序**：按 y 自上而下扫描；遇到跨栏块就把当前段（先左栏后右栏、栏内按 y）吐出，再吐该跨栏块；扫完吐出最后一段。

## 阈值

| 常量 | 值 | 作用 | 调大的后果 |
|---|---|---|---|
| `HEADER_BAND` | 0.075 | 页眉判定的页高比例 | 会把正文首行当页眉删掉 |
| `FOOTER_BAND` | 0.925 | 页脚判定的页高比例 | 会把正文末行/脚注当页脚 |
| `GUTTER_SEARCH` | (0.18, 0.82) | 栏缝允许出现的横向范围 | 靠近页边的窄栏可能漏检 |
| `MIN_GUTTER` | 0.020 | 栏缝最小宽度（页宽比例） | 窄缝漏检，页面退化成单栏 |
| `GUTTER_COVER_RATIO` | 0.40 | 栏缝窄条允许的覆盖比例 | 跨栏块多时会找不到缝 |
| `MAX_COLUMNS` | 3 | 最大栏数 | 更多栏的版面会被并成一栏 |
| `MIN_BODY_CHARS` | 40 | 判定"无可用文字层"的页字符数 | 短页（如纯图页）会被误判为扫描页 |

调参原则：先看 `layout.page_columns` 与肉眼是否一致，再看 `reading_order_text` 是否有整句被栏边界拼断。**不要**为了单个页面反复放宽阈值——放宽 `GUTTER_COVER_RATIO` 会让单栏页被假切成两栏，代价更大。

## 无文字层与扫描件

判定依据是**正文块字符数**，不是页面上有没有图片。低于 `MIN_BODY_CHARS` 的页：`columns = 0`，不参与排序，并写入 `warnings` 与 `uncertainty`。不做 OCR，也不根据文件名或标题猜想内容。

## 已知版面伪影

| 现象 | 原因 | 处理建议 |
|---|---|---|
| 图内坐标轴刻度、图例混入正文 | PDF 里图内文字也是文字对象 | 按 `bbox_norm` 定位到图区后人工剔除，或在下游按短块过滤 |
| arXiv 侧边水印出现在正文开头 | 水印在左页边距，未被页眉页脚规则覆盖 | 当作独立 `unit` 忽略；需要时按 `bbox_norm[0] < 0.08` 过滤 |
| 通栏摘要被判为单栏 | 摘要实际排版宽度小于跨栏判定 | 顺序不受影响，只影响 `column_kind` 标记 |
| 脚注与正文混排 | 脚注在页底但未进入 7.5% 页脚带 | 可下调 `FOOTER_BAND` 或在后处理按字号过滤 |

## 验证方法

1. 用合成 PDF 回归：`product-arena-08/test/synthetic-2col.pdf` 覆盖了通栏标题、通栏图注、单栏页三种情形，正确顺序是左栏 1–4 → 右栏 1–4，图注之后左栏 7–8 → 右栏 7–8。
2. 用真实论文抽查：任一页 `reading_order_text` 里取一段，和 PDF 阅读器同位置逐字比对。
3. 稳定性：同一 PDF 连跑两次，`sha256` 与 `units[].unit_id` 必须完全一致。
